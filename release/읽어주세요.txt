우리들의 가족 (ぼくらの家族) 한글패치 v{{VERSION}}
=================================================

PS2 일본판 「ぼくらの家族」 (SCPS-15088) 비공식 한글패치입니다.
원본 ISO에 차이 패치(xdelta)를 적용해 한글판 ISO를 새로 만듭니다. 원본 ISO는 바뀌지 않습니다.

※ 번역과 검수는 AI(Claude)가 했습니다. 사람의 문장별 검수는 하지 않았습니다.
  오역·어색한 문장·글자 넘침을 보시면 제보해 주세요.


준비물
------
- 일본판 「ぼくらの家族」 ISO (SCPS-15088)
  SHA1: {{SRC_SHA1}}
  (Windows에서 확인: 명령 프롬프트에서  certutil -hashfile "원본.iso" SHA1)
- 에뮬레이터 PCSX2 (실기는 확인하지 않았습니다)


Windows에서 적용
----------------
1. 받은 zip을 완전히 풉니다 (zip 창 안에서 바로 실행하지 마세요).
2. 원본 ISO를 「한글패치_적용.bat」 위에 끌어다 놓습니다.
   (또는 원본 ISO를 이 폴더에 넣고 「한글패치_적용.bat」을 더블클릭)
3. 「완료」가 나오면 이 폴더에 {{OUT_NAME}} 이 생깁니다.
   Windows 보안 경고가 뜨면 「추가 정보 → 실행」을 누르세요. 서명하지 않은 팬 제작 스크립트라서 뜨는 경고입니다.


Linux / macOS에서 적용
----------------------
xdelta3가 필요합니다 (Debian·Ubuntu: sudo apt install xdelta3, macOS: brew install xdelta).

    sh apply.sh "Bokura no Kazoku (Japan).iso"

원본과 결과의 SHA1을 모두 확인한 뒤 「완료」를 출력합니다.


다른 도구로 직접 적용
---------------------
patch/{{PATCH_FILE}} 은 표준 xdelta3(VCDIFF) 파일입니다. xdelta UI, Delta Patcher 같은 도구로도 적용할 수 있습니다.

    xdelta3 -d -s "Bokura no Kazoku (Japan).iso" patch/{{PATCH_FILE}} "{{OUT_NAME}}"

결과 ISO의 SHA1: {{OUT_SHA1}}


플레이할 때
-----------
- 대사는 원작처럼 세로쓰기입니다.
- 이름은 한글 자모를 하나씩 눌러 조합합니다(ㄱ ㅣ ㅁ → 김). 조합되는 글자는 완성형 2,350자입니다.
  × 버튼으로 자모 단위로 지웁니다.
- 원작의 일본어 음성은 그대로입니다.
- 일본판 세이브와 섞어 쓰는 것은 확인하지 않았습니다.


한글화 범위
-----------
- 대사 전체, 시스템 메시지, 메뉴·설정·데이터(학교·책·직업·동아리 등), 기본 이름 목록
- 이름 입력(한글 자모 조합), 이름 뒤 조사 자동 선택(은/는, 이/가 …)
- 그림 속 글자: 타이틀 로고, 메뉴 아이콘, 미니게임 그림, 책 표지 61종, 앨범 사진 라벨 113장
- 입학시험 미니게임: 일본어 한자 문제를 한국어 문제(맞춤법·낱말 뜻·상식) 289개로 새로 출제
- 동영상: 오프닝 제목과 엔딩 15종의 제목 카드

일본어로 남는 것
----------------
- 오프닝·엔딩 동영상의 스태프 크레딧
- 메뉴 소개 화면 배경 사진 속 간판 등 (도쿄 배경 그대로)
- 책 표지의 작은 저자·출판사 표기
- 메모리 카드 저장 이름 (PS2 본체 화면은 한글을 표시하지 못함)

확인한 범위
-----------
PCSX2에서 타이틀·새 게임·이름 입력·오프닝·프롤로그·첫 아이 출생·첫 행동 메뉴까지 확인했습니다.
게임을 처음부터 끝까지 이어서 플레이하지는 않았고, 엔딩 동영상은 게임 안에서 재생해 보지 않았습니다.
