## 2. 확인된 구조 (사실)

### 2.1 XAPF 아카이브 (`DATA/*.XAP`)
- 헤더 `XAPF`, `+8` BODY 청크 오프셋. `0x10 'FILE'`, `0x1C` 항목 수, `0x20`부터 32바이트 항목
  (`name_off(0x18 기준)`, `flags`, `data_off(절대)`, `size`, `csize`, `date`, `time`, `pad`).
- 모든 항목 `flags = 1` (LZ 압축). MAP/CHR 안에는 XAP가 한 겹 더 들어 있음.
- 압축 해제 루틴: `SCPS_150.88 @ 0x249958` → `tools/xaplz.py`로 옮김.
  비트 스트림(MSB 우선 플래그 바이트가 데이터 사이에 끼움):
  `0`=리터럴, `1 0 b`=짧은 오프셋 `b-256`(b=0이면 끝), `1 1 b 4비트`=긴 오프셋,
  길이는 감마식(`n=1; while bit: n=n*2+bit`) 후 `n+1`바이트 복사.
- **검증**: 원본의 모든 항목 6,498개가 선언된 크기와 정확히 같게 풀림.
- 매직 비교 `0x2496e0` (`XAPF`).

### 2.2 텍스트 = 런타임에 파싱되는 Shift-JIS 원문 텍스트
게임이 `.txt` / `.mes` 원문을 실행 중에 직접 읽는다(컴파일된 테이블 아님). 포인터 테이블이 없어서
문자열 길이가 바뀌어도 재배치 문제가 없음.

- 이벤트 대사 `EVENT.XAP/*.mes` (1,517개, 짝을 이루는 `.scb`는 바이트코드 — 일본어 문자열 없음).
  형식: `라벨[, 음성 길이]` 다음 줄에 탭 들여쓰기 본문, `@n` 줄바꿈, `,` 단락(음성 구간) 구분,
  `$OTO$`/`$MAIN$`/`$USER$` 같은 이름 변수.
- 시스템/메뉴: `SYSMES`, `GAMEMES`, `MENURES/menumes.txt`, `MENU/*info.txt`, `GAMEDB/*.txt`,
  `RESORTDB`, `RESNAME`, `NAMEDB`, `MINIG/*` (퀴즈 `qdata.txt`, `quest.txt`), `DEMO/curflag.txt`.
- 서식 코드 예: `@r115@g108@b53@s20…` (색·크기), `@n`.

### 2.3 폰트 (`FONT.XAP`)
- `font20.moj`: `MOJI` 헤더, 셀 20×20, **글리프 3,681개**, 12바이트 항목 `u16 SJIS코드, s8 x보정, s8 y보정,
  u32 (y<<16|x) 아틀라스 위치, u8 폭, u8 높이, u16 0`. 코드 오름차순 정렬(이진 탐색 추정), **가변폭**.
- `font20.xim`: 4bpp 알파 팔레트(흰색, 알파 0–0x80) 아틀라스 **256×6636**.
- 렌더링 검증: 아틀라스에서 `ねえ私たち出会ってから`를 조립해 원본과 같은 글자가 나옴(정적 확인).
- `vcode.txt`: 세로쓰기용 문장부호 치환 표.

### 2.4 실행 파일 안의 일본어
- `ぼくらのかぞく`(메모리 카드 저장 이름 추정), `ああああ`(기본 이름 추정), 가나 50음 표(이름 입력 색인 추정).
- 이름 입력용 한자 목록 `MENU.XAP/kanji.txt` (가나 색인 `[a] [i] …` 별 한자).

### 2.5 그림 글자
- `MENU.XAP` tm2 903장: 앨범 사진 캐릭터 라벨(`ゲンコツ 07歳～ 無気力` 등), 책·잡지 표지, 학교 간판 등.
- 그 밖에 `TITLE`(로고·`PRESS START BUTTON`), `MENURES` 24장, `INTERF`, `MINIG/*` 미니게임 그림 글꼴, `LOGO`.
- 동영상 `MOVIE/*.PSS` 16개(오프닝·엔딩) — 글자가 있는지 아직 미확인.
- MAP/CHR의 txt는 개발 주석에만 일본어가 있어 번역 대상 아님.

## 5. 진행 / 위험 표

| 미해결 조건 | 다음 증거 |
|---|---|
| LZ 압축기 + XAP 재작성이 게임과 호환되는가 | 압축기 작성 → 원본 내용 그대로 재압축한 ISO가 부팅·동일 동작 (무변경 왕복) |
