# PoC 기록

## PoC1 — 한글 폰트 + 대표 문장 (가시성·종단 간) — **통과** (2026-11-11)

- 빌드: `tools/build_poc1.py work/orig.iso work/build/poc1.iso` (개발 정책 `allow_kanji=True` — 배포 후보 아님)
- 결과 ISO SHA1: `8e084d2e571055fa048654c21c7e15955698ef89`
- 변경: `FONT.XAP`(한자 2,979자 제거, KS X 1001 한글 2,350 + 자모 51 추가, 3,103자, 아틀라스 256×5522),
  `MENURES.XAP/menumes.txt` 000–003(타이틀 메뉴), `EVENT.XAP/000h0a.mes` 3줄.
  세 파일 모두 자체 압축기로 재압축·재조립하고, ISO는 파일 순서를 유지하며 뒤 파일을 밀어 배치.
- 환경: PCSX2 2.8.2, BIOS scph39001.

### 관찰
| 화면 | 결과 |
|---|---|
| 타이틀 메뉴 | `새게임 / 이어하기 / 가족의기록 / 설정` 정상 표시 (`@s` 자간 코드 그대로 동작) |
| 시나리오 선택·이름 확인 창 | 한자가 있던 자리에 한글 글리프가 나옴 (예상대로 — 미번역 한자) |
| 오프닝 이후 프롤로그 대사 (`000h1a`) | **세로쓰기** 메시지 창. 한자 자리에 한글 글리프가 세로로 그려짐 |
| 아기 이름 결정 창 | `新規作成 / リストから選ぶ` 선택지 표시 |

### 확정된 사실
- 자체 LZ 압축기 출력과 XAP 재조립을 게임이 그대로 읽는다.
- 파일 크기가 바뀌어 LBA가 밀려도 게임이 찾는다 (ISO9660 디렉터리 기준 조회).
- 폰트 표 개수·아틀라스 크기가 원본보다 작으면 문제없이 쓰인다. 한자 코드 영역(0x889F~)에 둔 한글이 가로·세로 경로 모두에서 그려진다.

### 새로 드러난 범위
- 세로쓰기 대사 창 → D5: 세로쓰기 유지로 결정됨.
- 오프닝 동영상(`OPENING.PSS`)에 스태프 크레딧·제목이 영상에 박혀 있음 → 동영상 재인코딩 필요 (D2 범위).
- 이름 입력: `新規作成`(새로 만들기) 경로 → PoC2에서 처리.

### 아직 확인 안 된 것
- `000h0a` 대사(바꾼 3줄)는 이번 진행 경로에 나오지 않았다 — 표시 확인은 `000h1a`의 미번역 줄로만 함.
- 메시지 창 한 줄 최대 폭·줄 수.

## PoC2 — 이름 입력 자모 조합 (D6) — **통과** (2026-11-11)

- 빌드: `tools/build_poc2.py work/orig.iso work/build/poc2.iso` (PoC1 + 실행 파일 패치 + `MENU.XAP/kanji.txt`)
- 결과 ISO SHA1: `32c83848a441e1305574594947df22f13003b73d`
- 실행 파일 변경 (`tools/elfpatch.py`, 원본 워드 검증 후 패치):
  - bss 끝(`_end=0x4254AC`) 뒤 `0x425500`에 PT_LOAD 구간 추가(약 6.8KB: 트램펄린 + 조합 코드 + KS 표).
  - 힙 시작을 새 끝으로 이동: crt0 `SetupHeap`(`0x1001D0/D8`), `_end` 반환 함수(`0x22B768/70`), 데이터 워드 `0x2BDA94`.
  - 훅 3곳: 글자 확정 `0x1A5DB0`, 왼쪽 판 지우기 `0x1A5694`, 오른쪽 판 × `0x1A54C0`.
- 조합 코드 (`tools/ime_asm.py`)는 Python 참조 구현(`tools/hangul_ime.py`)과 Unicorn 에뮬레이션으로 대조(무작위 1,500 시퀀스 포함).
- 데이터: 왼쪽 첫 칸 라벨 `한`, `[a]` 구역 = 자음 19 + 모음 21 배치(6열).

### 관찰 (PCSX2)
| 입력 | 결과 |
|---|---|
| ㄱ ㅣ ㅁ | `김` — 확정 뒤에도 오른쪽 자모판에 머묾 |
| 이어서 ㅣ | `기미` (받침이 다음 글자로 넘어감) |
| 오른쪽 판에서 × 반복 | `김 → 기 → ㄱ → (빈칸)` 오른쪽 판 유지, 칸 시작에서 × 는 원작처럼 왼쪽 판으로 |
| 왼쪽 판에서 × 반복 | `기미 → 기ㅁ → 기 → ㄱ` 자모 단위 지우기 |

### 남은 일 (이름 입력)
- 왼쪽 판의 빈 칸으로 커서가 가면 빈 구역이라 페이지 표시가 깨짐(`1/71582789`) → 왼쪽 판 구성(한글/영문/기호 등)과 모든 구역 채우기 설계.
- 이름 확정 뒤 대사·메뉴에서 한글 이름 표시 확인, 기본 이름·이름 목록(`NAMEDB`) 한글화.
- 이름 뒤 조사(은/는, 이/가 …) 처리.
- 버튼 문구(`1文字戻る`, `決定`, `名前へ(L1)`, `苗字へ(R1)`, `英数`, `記号`, `空白`) 번역.
