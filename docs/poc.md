- 빌드: `tools/build_poc1.py work/orig.iso work/build/poc1.iso` (개발 정책 `allow_kanji=True` — 배포 후보 아님)
- 결과 ISO SHA1: `8e084d2e571055fa048654c21c7e15955698ef89`
- 변경: `FONT.XAP`(한자 2,979자 제거, KS X 1001 한글 2,350 + 자모 51 추가, 3,103자, 아틀라스 256×5522),
  `MENURES.XAP/menumes.txt` 000–003(타이틀 메뉴), `EVENT.XAP/000h0a.mes` 3줄.
  세 파일 모두 자체 압축기로 재압축·재조립하고, ISO는 파일 순서를 유지하며 뒤 파일을 밀어 배치.
- 환경: PCSX2 2.8.2, BIOS scph39001.

### 관찰
| 화면 | 결과 |
|---|---|
| 타이틀 메뉴 | `새게임 / 이어하기 / 가족의기록 / 설정` 정상 표시 (`@s` 자간 코드 그대로 동작) |
| 시나리오 선택·이름 확인 창 | 한자가 있던 자리에 한글 글리프가 나옴 (예상대로 — 미번역 한자) |
| 오프닝 이후 프롤로그 대사 (`000h1a`) | **세로쓰기** 메시지 창. 한자 자리에 한글 글리프가 세로로 그려짐 |
| 아기 이름 결정 창 | `新規作成 / リストから選ぶ` 선택지 표시 |

### 확정된 사실
- 자체 LZ 압축기 출력과 XAP 재조립을 게임이 그대로 읽는다.
- 파일 크기가 바뀌어 LBA가 밀려도 게임이 찾는다 (ISO9660 디렉터리 기준 조회).
- 폰트 표 개수·아틀라스 크기가 원본보다 작으면 문제없이 쓰인다. 한자 코드 영역(0x889F~)에 둔 한글이 가로·세로 경로 모두에서 그려진다.

### 새로 드러난 범위
- 세로쓰기 대사 창: 한국어로 세로쓰기를 유지할지, 가로로 바꿀지 결정이 필요하다.
- 오프닝 동영상(`OPENING.PSS`)에 스태프 크레딧·제목이 영상에 박혀 있음 → 동영상 재인코딩 필요 (D2 범위).
- 이름 입력: `新規作成`(새로 만들기) 경로가 D3 대상. 아직 화면 미확인.

### 아직 확인 안 된 것
- `000h0a` 대사(바꾼 3줄)는 이번 진행 경로에 나오지 않았다 — 표시 확인은 `000h1a`의 미번역 줄로만 함.
- 메시지 창 한 줄 최대 폭·줄 수.
