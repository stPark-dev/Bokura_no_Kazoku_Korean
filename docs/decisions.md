# 사용자 결정 기록

각 결정은 ID로 참조한다. 바뀌면 지우지 않고 상태를 `superseded`로 두고 새 항목을 단다.

## D1 번역·검수 담당 — adopted (2026-11-11)
- 질문: 초벌 번역과 검수를 누가 하는가.
- 결정(사용자): **초벌 번역과 검수를 모두 Claude가 맡는다** (GPT 검수 없음).
- 영향: 검수 상태는 Claude 검수 기준으로 기록한다. 사람이 문장별로 검수하지 않았다는 점은 배포 안내에 밝힌다.
- 재검토: 사용자가 사람 검수나 외부 검수를 추가하기로 할 때.

## D2 한글화 범위 — adopted (2026-11-11)
- 질문: 그림 글자·동영상까지 포함할지.
- 결정(사용자): **처음부터 전부 한글화를 목표로 한다** — 대사·메뉴·데이터 텍스트, 그림 글자(앨범 라벨·표지·타이틀·미니게임 등), 동영상 속 글자까지.
- 영향: 그림 글자 카탈로그와 PSS 동영상 조사가 필수 작업이 된다. 범위를 줄이려면 근거를 들어 다시 결정을 받는다.
- 예외 후보(결정 필요 시 다시 묻기): PS2 BIOS가 표시하는 메모리 카드 저장 이름 — BIOS 글꼴에 한글이 없음.

## D3 이름 입력 — adopted (2026-11-11)
- 질문: 이름 입력을 어떻게 한글화할지.
- 결정(사용자): **한글 조합 입력이 가능해야 한다** (초성·중성·종성을 조합해 임의의 한글 이름 입력).
- 영향: 이름 입력 화면 코드 훅/재설계가 필요하다. 입력 가능한 글자를 조합해 만들 수 있어야 하므로, 폰트에 들어갈 한글은 대사에 쓰인 글자만이 아니라 **KS X 1001 한글 2,350자 이상**(또는 조합 가능한 전체)을 확보해야 한다. 이름 뒤 조사 처리도 같이 설계한다.

## D4 제목 — adopted (2026-11-11)
- 결정(사용자): 한국어 제목은 **우리들의 가족**.
